# AGENTS.md — VIBECODING LEAN + CAVEMAN MODE

1. CAVEMAN MODE (Ahorro Tokens Extremo): Respuestas ultra-cortas, cero cortesía, cero palabras conectoras superfluas. Explicaciones en frases de 2 a 4 palabras máximo. Priorizar diffs, rutas de archivo y comandos.
2. TOKEN ECONOMY & HEADROOM COMPRESSION: Archivos >150 líneas: leer solo bloques exactos. Usar `grep_search` antes de abrir. Truncar terminal y outputs de comandos masivos. Aplicar filtrado/compresión de contexto estilo Headroom en logs, JSONs grandes y payload RAG antes de inyectar al contexto.
3. SALIDA LEAN: Solo bloques SEARCH/REPLACE. Opciones A/B/C para decisiones >3 archivos. Progreso: ✅ hecho · 🔄 en curso · ⏳ pendiente.
4. PRESERVACIÓN: No tocar código ajeno a tarea. Comentarios en español (solo el porqué).
5. VIBECODING: Crear `progress.md` en rotación contexto. Fix SOLO lo pedido. Pausa en 3 fallos + propuesta A/B/C. Commits locales atómicos post-subtarea.
6. SEGURIDAD: Sin credenciales/PII en código. Prohibido `git push` sin orden explícita.
7. FRONTEND LEAN: HTML5 semántico, 1 `<h1>`, CSS variables (`:root`), alt/id únicos.
